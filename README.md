# Что делает скрипт?
Скрипт собирает информацию о сервере каждые 30 секунд. Это сколько оперативной памяти занято и свободно, 
использование дискового пространства, а также время работы сервера

Всю информацию скрипт заносит в файл `monitor.log`. Пример работы скрипта можно увидеть в файле `sample_output.txt`

# Как запустить и как остановить
## Запуск
Чтобы запустить скрипт необходимо выполнить команду `./script.sh`

## Остановка скрипта
Для его остановки необходимо воспользоваться сочетанием клавиш `Control + C`

# Что можно настроить?
В скрипте можно настроить следующее, через переменные:
- `INTERVAL` - время, через которое будет проводиться сбор информации о сервере, указанное в секундах
- `LOG_FILE` - файл, куда будут записываться логи

Переменные лежат в начале файла `script.sh`

# Какие проверки идут перед стартом и что будет, если они не прошли
Ниже описаны валидации, которые проверяются через скрипт. Если запуск не проходит валидацию, то скрипт
останавливается и выводит сообщение об ошибке с указанием проблемы

## Проверка на валидацию интервала запуска
Проверка нацелена на отлавливание некорректных значений интервала. Значение должно быть целым числом больше 0

## Проверка на доступность к изменению
Проверка нацелена на отлавливание проблем, если папки, указанной в пути к лог-файлу, не существует. А также,
если у пользователя нет права на запись туда

## Проверка на возможность запускать команды 
Проверка на наличие команды free uptime и df. Если нет, то скрипт об этом сообщит
